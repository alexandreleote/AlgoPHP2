

# Algo PHP -2
## 📋 Contexte du projet
Exercices d'algorithme PHP - Dans cette phase avancée, l'objectif est d'apprendre à manipuler les **fonctions personnalisées** en PHP, en utilisant le mot-clé `return` pour structurer et modulariser le code. De plus, les concepts fondamentaux des **chaînes de caractères** (comparaison, manipulation et recherche) seront approfondis pour résoudre des problèmes courants.
## 🎯 Objectifs pédagogiques
Maîtriser les principes des algorithmes : variables, chaînes de caractères, conditions, boucles, tableaux, dates, programmation orientée objet.

Exploiter des ressources en ligne de référence telles que : PHP.net, Developpez.com ou W3Schools.com

## 🔧 Technologies utilisées
Langages :
- PHP 

Outils :
- VSCode
- Git/GitHub

## 💡 Concepts clés abordés

- Modification d'un texte grâce à une fonction
- Création d'un formulaire avec un tableau de champs à remplir
- Retourner une valeur contenant une chaîne de caractères
